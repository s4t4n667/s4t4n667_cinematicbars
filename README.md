# s4t4n667_cinematicbars
## Simple cinematic bar overlay 🖼️🪄

Simple in-game command that adds a black bar overlay.

- Standalone
- Automatically detects jg-hud and 0r-hud-v3, or can add custom hud exports to client.lua
