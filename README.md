## Cinematic bar overlay 🖼️🪄

Simple in-game command that adds a black bar overlay.

## ✨ Features:
- Automatically detects jg-hud and 0r-hud-v3, or can add custom hud exports to client.lua
- 4 different bar thickness options by default
- Locales: English, French and German

## 🔐 Dependencies:
- [ESX](https://github.com/esx-framework/esx_core), [QBCore](https://github.com/qbcore-framework) or [Qbox](https://github.com/Qbox-project/)
- [ox_lib](https://github.com/overextended/ox_lib)

## 🔗 Useful links:
- [Documentation](https://s4t4n667.gitbook.io/asgaard-developments/free-scripts/s4t4n667_cinematicbars)

## ⚙️ How to install:
1) Download the latest release
2) Add `s4t4n667_cinematicbars` to your server's `resource` folder
3) Adjust the `config.lua` to your liking
4) Restart your server

## 📊 Resmon:
0.00ms when idle, 0.01ms when in use
